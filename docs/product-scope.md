# PortNest 首版范围

PortNest 是面向开发者的桌面端口管理工具，主要用于辨认和清理开发项目、Agent 留下的监听服务，并辅助排查端口占用。

状态：首版代码和本地 `.app` 已交付，真实双端口服务的正常关闭与强制关闭链路已通过原生界面验收。错误和隐藏轮询策略另有模拟回归；实际登录启动等未验证边界见 [验收记录](acceptance.md)。本文仍用于记录目标行为。

## 已确认决策

- 使用 Tauri 2、React、TypeScript 和 Rust，设计自己的产品界面与交互。
- 首版支持 macOS；Windows 和 Linux 留待后续适配。
- 先在用户自己的 Mac 上验收，再考虑开源发布。
- 首版包含端口列表、项目归属识别、进程详情和安全关闭。
- 首版不包含 CLI、固定域名、HTTPS 代理和项目启动功能。

## 关闭操作

- 关闭对象是选定进程；确认框列出该进程的全部监听端口，说明这些端口都会受到影响。
- 首版只关闭选定进程，不递归关闭子进程，不提供批量关闭。
- 先请求正常退出并等待最多 5 秒。仍在监听时提供手动强制关闭，执行前再次明确确认。
- 系统服务、其他用户进程和 App 进程可查看，但受保护，不能通过 PortNest 关闭；首版不请求管理员权限。
- 无法识别项目的当前用户进程，只有身份核验充分时才允许在详情中确认关闭。无法核验身份时拒绝操作。
- 身份核验和影响范围确认同样适用于强制关闭。
- 执行关闭前重新核验目标进程身份与当前监听情况；身份或影响范围变化时中止操作并要求重新查看，不能仅凭过期列表中的 PID 发送信号。

## 界面与网络行为

- 常用操作位于菜单栏弹出面板，设置位于独立窗口。
- 支持按端口、进程和项目搜索，以及展开行查看详情。
- 首版只读取系统与本地文件信息，不自动请求监听端口、不联网获取图标、不主动检查更新或发送遥测。
- 浏览器访问由用户点击触发。

## 扫描与项目归属

- 只扫描 TCP 监听，覆盖 IPv4 和 IPv6；首版不包含 UDP。
- 显示实际绑定地址，并区分“仅本机”与“可能对局域网开放”。后者仅描述绑定范围，不代表已验证网络可达性。
- 从进程工作目录向上寻找最近的项目标记，以实际项目目录作为归属单元。
- 不同 worktree、可独立识别的子项目分别展示；无法确认时显示“未知归属”。

## 刷新与偏好

- 打开菜单栏面板时立即刷新；面板展开期间每 5 秒刷新，隐藏后停止轮询，并提供手动刷新。
- 扫描失败时保留上次成功结果，明确显示错误和结果更新时间；不能把扫描失败显示成没有监听服务。
- 默认不开机自启，在设置中提供登录启动开关。
- 默认中文，主题跟随系统。

## 首版验收标准

1. 交付能够在用户 Mac 上运行的 `.app`，显示菜单栏入口、端口面板与设置窗口。
2. 使用专门创建的真实本地测试服务，完成“发现 → 搜索 → 查看归属 → 确认关闭 → 验证端口释放”的用户链路，并保留可重复步骤。
3. 使用同一进程监听多个端口的测试服务，确认界面列出全部受影响端口，关闭后的各端口状态与真实结果一致。
4. 使用拒绝正常退出的测试服务，确认最多等待 5 秒后展示明确失败反馈，只有再次确认才执行强制关闭，并核验结果。
5. 为受保护进程、身份变化、身份信息缺失和归属未知的关闭策略提供可运行的安全回归检查；明确区分模拟边界检查与真实运行验收。
6. 检查空列表、搜索无结果、加载中、扫描失败、关闭失败与旧结果提示；检查面板隐藏后的轮询停止，以及登录启动和主题设置。

运行验收仅操作专门创建的测试服务；对已有服务的检查采用只读方式，不把用户正在使用的开发服务当作关闭测试目标。首版完成状态以真实用户链路和上述检查结果为依据。
