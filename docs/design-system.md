# PortNest 界面设计

采用安静、紧凑的 macOS 菜单栏工具布局：品牌与刷新操作在顶部，搜索紧随其后，以进程为单位展示监听端口，详情在行内展开；受保护项折叠在列表末尾，设置独立打开。

主色为青绿 #087F73，浅色背景 #F4F7F8、面板 #FFFFFF、主文字 #192D32、次要文字 #55686E，危险操作用 #B42336；暗色主题保持同一语义并提升文字对比。半透明只用于窗口材质与工具栏，操作区域保持可读。

字体使用本机系统字体与中文字体，端口数字使用本机等宽字体；不联网加载字体或图标。采用单一线条图标风格、明确焦点和按钮状态，尊重减少动效设置。

设计检索建议的文档落地页、远程字体和暗色专用模式不符合菜单栏工具、离线使用和跟随系统主题的要求，因此不采用。仅保留其紧凑信息密度、明确状态与可访问性建议。
